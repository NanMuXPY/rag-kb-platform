- `workspace.py`：`kbs` 迁移新增 6 字段（code/dept/level/owner/status/updated_at，含历史回填）；`create_kb`/`update_kb_meta`/`touch_kb`/`candidate_users`/`all_group_grants`；`readable_kb_ids` 排除归档库；`set_group_grant` 校验分组存在

- `api/main.py`：`GET /kbs` 支持 q/dept/level/status 过滤 + 统计列；`PATCH /admin/kbs/{id}`；`GET /admin/kb-matrix`；`GET /kbs/{id}/candidate-users`；上传/审批/删除刷新 `updated_at`；**下载接口放行 uploader 本人**（修 B6：否则传完自己都打不开）

### frontend（已部署，bind-mount 直接 scp）
- `index.html`：`#viewKb` 拆为 `#kbList`（工具条+表格+卡片+批量条+分页）与 `#kbDetail`（面包屑+页头+二级导航+四分区）；控制台加「权限矩阵」页签；`#confirmDialog` / `#kbFormDialog` 两个 dialog

- `app.css`（961→约 2000 行）：后台令牌 24 个 + 表格/徽标（分级线框戳/状态圆点/范围前缀）/二级导航/矩阵/抽屉/骨架等全套

## 三、过程中修复的真实 bug

1. **表格列错位（本会话主理人热修）**：`no-check` 模式用 `display:none` 移除复选框单元格，但 `<colgroup>` 仍是 11 列 → 后续列整体左移一格，「知识库」名称列掉进 0 宽坑，右侧留白 100px。修复：复选框列常驻，删除 `.no-check`。教训已写进视觉规范：**要移除列必须同时移除 col 与所有 td**。
2. B6（上传者无法下载自己的待审文件）→ 后端放行 uploader。
3. B3（孤儿分组授权）→ 后端校验存在性，400 返回可读文案。
4. B1（`updated_at` 不随文件变动）→ 上传/审批/删除均刷新。
