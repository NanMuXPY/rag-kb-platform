# 微信云开发常见报错与规避方法

## 问题一：云数据库集合不存在

**现象**：小程序端调用 `db.collection('todos').add()` 报错集合不存在。

**原因**：云开发不会根据代码自动建集合，集合必须在云开发控制台**手动创建**后才能读写。

**解决**：上线前在控制台逐一核对代码里引用的所有集合名，提前建好并设置权限规则。

## 问题二：控制台导入数据失败

**现象**：准备好 JSON 文件在控制台导入集合，一直导入失败。

**原因**：控制台导入要求两点同时满足：文件扩展名必须是 `.json`；文件内容是 **JSON Lines 格式**（每行一个独立 JSON 对象），而不是一个整体 JSON 数组。

**解决**：把 `[ {...}, {...} ]` 改写成每行一个对象的格式：

```
{"name": "高数", "day": 1}
{"name": "英语", "day": 2}
```

## 问题三：真机与模拟器表现不一致

**现象**：开发者工具模拟器一切正常，真机预览时布局错位、字体截断。

**排查清单**：

- 自定义字体/字号是否做了机型适配（长文本按长度缩放而不是固定截断）；
- 是否用了模拟器支持但真机不支持的 CSS 属性；
- rpx 与 px 混用导致不同屏幕宽度下换算差异；
- 云函数日志与小程序端 console 分开看，真机问题先在真机调试模式下复现。

## 通用习惯

- 数据库字段设计先定好粒度（如课表按"每日一行"还是"每节课一行"），中途迁移成本高；
- 本地调试文件、测试集合用完及时清理，避免控制台残留脏数据干扰联调。
